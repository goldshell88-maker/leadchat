# Что нужно создать в Авито, чтобы подключить аккаунты

Список для владельца. Делается **один раз** — дальше аккаунты подключаются
кнопкой.

> **Честная оговорка.** Названия полей и кнопок в кабинете Авито я не вижу —
> доступа к нему у меня нет, а сайт закрыт для машинного чтения. Всё, что ниже
> помечено «дословно», взято из официальной спецификации API Авито и потому
> точно. Названия самих полей в кабинете могут отличаться формулировкой —
> сверяйтесь по смыслу, и если что-то не сходится, пришлите снимок экрана.

---

## 1. Куда идти

**developers.avito.ru** — кабинет разработчика. Вход под учётной записью Авито.

Заходить нужно **под учётной записью того аккаунта**, который подключаете:
ключи принадлежат ей, а не вам как человеку. Разбор решения — `docs/25`.

## 2. Что создать

**По приложению на каждый аккаунт Авито.**

> **Исправление от 8 августа.** Здесь было написано «достаточно создать одно
> приложение под любой из ваших учётных записей — оно будет подключать все
> остальные». Это верно для подключения через согласие, но мы перешли на
> подключение по ключам, а там всё иначе: пара `client_id`/`client_secret`
> даёт доступ ровно к тому аккаунту, в кабинете которого она создана.
>
> Практически это выглядело так: вы вводите одни и те же ключи для второго
> аккаунта, система находит уже подключённый и обновляет его — в списке
> по-прежнему один канал. Отсюда «я могу подключить только 1 аккаунт».
> Теперь система об этом честно говорит, но ключи всё равно нужны свои.
>
> Значит: девять аккаунтов — девять приложений, девять пар ключей. Заводятся
> они в кабинете разработчика КАЖДОГО аккаунта, под его учётной записью.

| Поле | Что указать |
|---|---|
| Название | Любое узнаваемое, например `LeadChat` |
| Тип доступа | **Стороннее приложение** / доступ к данным других пользователей (authorization_code). НЕ «личная учётная запись» |
| Redirect URI | См. пункт 3 — самое важное поле |
| Права | См. пункт 4 |

## 3. Redirect URI — символ в символ

```
https://<адрес прода>/api/v1/avito/callback
```

Эту же строку показывает мастер подключения в LeadChat: **Настройки →
Аккаунты Авито → Подключить аккаунт**, второй шаг. Берите оттуда — так
исключается опечатка.

**Если не совпадёт хотя бы символом, Авито откажет в подключении**, и сообщение
об отказе будет невнятным. Это самая частая причина, по которой подключение не
идёт.

Если поле позволяет несколько адресов — впишите только этот.

## 4. Права (scope) — дословно

```
messenger:read
messenger:write
user:read
```

Что каждое значит (формулировки Авито):

* `messenger:read` — чтение сообщений в мессенджере Авито;
* `messenger:write` — модифицирование сообщений в мессенджере Авито;
* `user:read` — получение информации о пользователе.

Больше ничего не нужно. `items:info`, `stats:read` и прочие — не про переписку,
и просить их значит увеличивать шанс, что заявку будут дольше рассматривать.

Проверить себя легко: ровно эти три права стоят в ссылке подключения, которую
вы прислали из прежней системы.

## 5. Что забрать из кабинета

| Что | Куда |
|---|---|
| **Client ID** | Мастер подключения, шаг 3 |
| **Client Secret** | Туда же |

**Client Secret обычно показывается один раз.** Не закроете окно — не увидите
снова, придётся выпускать заново. Скопируйте сразу.

## 6. Куда вписать в LeadChat

**Настройки → Аккаунты Авито → Подключить аккаунт.**

Первый шаг мастера появится сам, если ключи ещё не заданы. Дальше:

1. вписываете Client ID и Client Secret;
2. **«Проверить и продолжить»** — система спросит у Авито токен приложения.
   Ответ приходит сразу: примут ключи или нет. Пусть ошибка всплывёт здесь, а
   не посреди подключения;
3. дальше — «Войти в Авито» под учётной записью первого аккаунта.

Если пароля от аккаунта у вас нет — там же **«Получить ссылку»**: отправьте её
тому, у кого он есть. Заходить в LeadChat этому человеку не нужно.

## Чего ожидать и что может пойти не так

**Заявка на доступ.** Авито может не выдать доступ к API мессенджера сразу —
встречается модерация заявки. Если увидите форму «расскажите, зачем вам API» —
пишите по делу: обработка переписки с покупателями в собственной системе
поддержки, свои аккаунты, стороннего доступа не предоставляется.

**Требование юрлица.** Доступ к API может требовать бизнес-аккаунта. Если
упрётесь — скажите, посмотрим, что можно сделать.

**Адрес возврата на sslip.io.** Наш адрес сейчас
`<адрес прода>` — это технический адрес, а не купленный домен.
Некоторые площадки такие адреса не принимают. **Проверьте это первым делом**:
остальное занимает минуты, а перевод системы на нормальный домен — дни, и
упирается в решение по `chat.partner-lead-centre.ru`, который сейчас занят
FreeScout.

## Коротко, одним списком

- [ ] Зайти на developers.avito.ru под учётной записью ПОДКЛЮЧАЕМОГО аккаунта
- [ ] Создать приложение (для подключения по ключам тип доступа значения не
      имеет — нужны только Client ID и Client Secret)
- [ ] Redirect URI: `https://<адрес прода>/api/v1/avito/callback`
- [ ] Права: `messenger:read`, `messenger:write`, `user:read`
- [ ] Скопировать Client ID и Client Secret (секрет — сразу, он показывается раз)
- [ ] Вписать их в мастер подключения и нажать «Проверить и продолжить»
- [ ] Подключить первый аккаунт — начать с одного, не с девяти
- [ ] Убедиться, что в списке каналов появилась НОВАЯ строка. Если система
      сказала «это тот же аккаунт, что уже подключён» — значит ключи взяты из
      кабинета уже подключённого аккаунта, нужны ключи другого
