# 10. UX и дизайн-система LeadChat

**LeadChat by Lead Partner** · «Мы ремонтируем — Вы зарабатываете»
Статус: зафиксировано · Источник палитры: CSS partner-lead-centre.ru (снято, данность)

> Место в пакете: этот документ — единственный источник истины по визуальному языку.
> Он **уточняет 03 §8** («Тема Lead Partner»): в 03 §8.1 тёмная тема была названа основной,
> а HEX-значения — плейсхолдерами «снять с сайта позже». Палитра снята: **сайт светлый**,
> поэтому светлая тема — основная, тёмная — опциональная; кортеж `lp` и переменные
> `--chat-*` из 03 §8.1 заменяются значениями из §1 ниже. Всё остальное в 03 (раскладка,
> брейкпоинты §8.2, виртуализация, WS) действует без изменений — здесь на него только ссылки.
> Экраны и сценарии — DESIGN §3; права и роли — DESIGN §5 и 01 §12; десктоп-специфика — 04.

Фокус: рабочий инструмент, в котором сотрудник живёт 8 часов в день. Значит: светло,
спокойно, плотно, ноль визуального шума; зелёный — акцент, а не заливка; каждое состояние
интерфейса отвечает на вопрос «что мне сделать дальше».

## 1. Токены

### 1.1. Принципы

- Все компоненты берут цвета **только** из CSS-переменных `--lc-*`; хардкод HEX в
  компонентах запрещён (иначе тёмная тема развалится).
- Переменные объявляются на `:root[data-mantine-color-scheme="light"]` и `...="dark"` —
  тот же механизм переключения, что в 03 §8.1 (`localStorage: leadchat-color-scheme`).
- Фирменный зелёный #3cc13b — это **акцент и индикатор**, не фон для текста: белый текст
  на нём даёт контраст 2.36:1 (провал AA, проверено арифметически — §6.1). Поэтому в
  системе есть токен «чернил» `--lc-primary-ink` и правило: на зелёном 500 пишем чернилами,
  белым пишем только на 700.

### 1.2. Шкала фирменного зелёного (общая для обеих тем)

Крайние и опорные точки — данность бренда: 50 = #d8f3d8 (subtle-фон сайта),
200 = #9ee09d и 300 = #8ada89 (светлые акценты сайта), 500 = #3cc13b (primary),
600 = #2ea32d (hover/darken), 700 = #1e7a1d. Промежуточные — интерполяция.

| Токен | HEX | Использование |
|---|---|---|
| `--lc-green-50` | `#d8f3d8` | subtle-фон: выбранная строка, пузырь исходящего, пилюля «В работе» |
| `--lc-green-100` | `#bfe9be` | hover subtle-элементов |
| `--lc-green-200` | `#9ee09d` | декоративные акценты, границы бот-пузыря |
| `--lc-green-300` | `#8ada89` | ссылки в тёмной теме, графики |
| `--lc-green-400` | `#63cf62` | focus-кольцо тёмной темы, графики |
| `--lc-green-500` | `#3cc13b` | **primary**: кнопки, точка online, активные контролы |
| `--lc-green-600` | `#2ea32d` | hover primary; focus-обводка светлой темы |
| `--lc-green-700` | `#1e7a1d` | ссылки светлой темы, бейдж непрочитанных, текст на green-50 |
| `--lc-primary-ink` | `#0c2e0c` | текст/иконки НА зелёном 500/600 (6.29:1 / 4.53:1) |

### 1.5. Маппинг на Mantine (заменяет кортеж из 03 §8.1)

```ts

// Шкала §1.2, дополненная крайними ступенями до 10 позиций Mantine

  "#9ee09d", // 3 — green-200 (бренд)

  "#3cc13b", // 6 — green-500 (primary бренда)
```

Proxima Nova — платный шрифт сайта: в вебе не грузим, он подхватится только там, где
установлен локально; фактический основной — **Inter** (variable, self-hosted woff2,
`font-display: swap`), метрически близкий fallback — Roboto.

## 2. Типографика

### 2.1. Шкала

| Токен | Размер/межстрочный | Вес | Использование |
|---|---|---|---|
| `--lc-fz-xs` | 13 / 18 | 400 | время, метаданные, системные строки, подписи под полями |
| `--lc-fz-sm` | 14 / 20 | 400 | **рабочий размер**: текст сообщений, строки списка, поля, кнопки |
| `--lc-fz-md` | 16 / 24 | 400–600 | заголовки панелей («Клиент», «Объявление»), имя в шапке диалога |
| `--lc-fz-lg` | 18 / 26 | 600 | заголовки страниц настроек, модалок |
| `--lc-fz-xl` | 24 / 32 | 600 | цифры карточек-метрик на /stats, заголовок логина |

Минимальный размер в продукте — 13px; ничего мельче не существует (это инструмент на
8 часов, глаза сотрудников — тоже ресурс). Исключение из шкалы одно: `MessageInput`
на мобильном — 16px (иначе iOS зумит поле, 03 §8.2).

Числа в метриках и таблицах — `font-variant-numeric: tabular-nums` (столбцы не «пляшут»).

### 2.2. Моноширинный

`ui-monospace, 'JetBrains Mono', ...` (см. theme) — для идентификаторов: `avito_user_id`,
ID диалога в отладочной строке, вебхук-URL в настройках аккаунта, коды ошибок в тостах
(`403 read_only_role`). Размер 13px, фон `--lc-bg-2`, радиус 4px, паддинг 1px 6px.

### 2.3. Иерархия в чате

Правило: в любой строке/пузыре ровно один элемент первого уровня, остальное тише.

| Элемент | Спека |
|---|---|
| Имя клиента в строке списка | 14/600 `--lc-text-1`; при непрочитанных не меняется (жирнеет не имя, а превью) |
| Превью последнего сообщения | 14/400 `--lc-text-3`, 1 строка, `text-overflow: ellipsis`; при непрочитанных — 14/600 `--lc-text-1` |
| Название объявления в строке | 13/400 `--lc-text-3`, 1 строка |
| Время в строке списка | 13/400 `--lc-text-3`; при непрочитанных — 13/600 `--lc-green-700` (в тёмной — green-300) |
| Текст сообщения в пузыре | 14/20, цвет пузыря (§4.6); ссылки — `--lc-link`, подчёркнуты |
| Имя оператора над пузырём | 13/600 `--lc-text-2` (показывается, если в диалоге писали ≥2 сотрудников — DESIGN §3.3) |

| Бейдж непрочитанных | 13/600 `--lc-unread-text` на `--lc-unread-bg`, min-width 20px |
| Дата-разделитель в ленте | 13/600 `--lc-text-3`, капсула на `--lc-bg-1`, по центру |

## 3. Сетка, плотность, форма

### 3.1. 8px-сетка

Все отступы и размеры кратны 8 (допускается 4 для внутренних микро-отступов):
`--lc-space-1..6` = 4 / 8 / 12 / 16 / 24 / 32. Иконки: 16 (в строках и кнопках), 20
(панель ввода), 24 (сайдбар). Высота контролов: 32 (компакт: фильтры, чипы), 36
(стандарт: кнопки, инпуты), 44 (мобильные тап-таргеты, 03 §8.2).

### 3.2. Три колонки рабочего места

Раскладка и брейкпоинты — 03 §8.2 (данность); здесь — фиксация размеров внутри
разрешённых диапазонов:

| Колонка | Ширина | Поведение |
|---|---|---|
| Сайдбар навигации | 56px фикс | только иконки + бейджи; тултипы справа |
| Список диалогов | **320px** по умолчанию, resize 280–360px (drag за границу, хранится в `localStorage`) | ≥1200px всегда видим |
| Переписка | `flex: 1`, min 480px | центр всегда живой |
| Карточка клиента | **320px** фикс (диапазон 300–340 — под будущие панели) | 768–1199px → `Drawer` (03 §8.2), кнопка «Клиент» в шапке |

### 3.3. Плотность списков

- Строка списка диалогов: **76px** (аватар 40, три текстовых ряда: имя / объявление /
  превью — макет 11 §2.1, совпадает с прототипом); паддинги 12px по горизонтали,
  8 по вертикали. Виртуализация — 03 §4.1, measure выключен (09 §2.5).
- Строки таблиц (сотрудники, статистика): 48px; компактный режим таблицы статистики — 40px.
- Пункты меню и выпадающих списков: 36px.
- Между пузырями сообщений: 4px в серии одного отправителя, 16px между сериями,
  24px вокруг даты-разделителя.

### 3.4. Радиусы и тени

| Токен | Значение | Где |
|---|---|---|
| `--lc-radius-sm` | 8px | кнопки, инпуты, чипы, пилюли-вкладки (= Mantine `md`) |
| `--lc-radius-md` | 12px | карточки, модалки, дроверы, пузыри сообщений, тосты |
| `--lc-shadow-1` | `0 1px 2px rgba(33,37,41,.06), 0 1px 3px rgba(33,37,41,.10)` | карточки, поповеры, строка-призрак при drag |
| `--lc-shadow-2` | `0 8px 24px rgba(33,37,41,.16)` | модалки, дроверы, меню |

В тёмной теме тени почти не читаются — глубина передаётся ступенями фона (bg-0→2)
и границей `--lc-border`; `--lc-shadow-2` остаётся для модалок (`rgba(0,0,0,.5)`).

## 4. Компоненты

Общие правила состояний: `hover` — фон/тон на ступень темнее (светлая тема) или светлее
(тёмная), 150мс; `active` — ещё на ступень плюс `transform: translateY(0.5px)`;
`disabled` — `opacity: .55` + `cursor: not-allowed`, цвета не переопределяются;
`focus-visible` — кольцо §6.2. Hover не появляется на тач-устройствах.

### 4.1. Кнопки (3 вида)

| Вид | Default | Hover | Active | Disabled | Focus |
|---|---|---|---|---|---|
| **Primary (filled)** — одно главное действие на экран: «Отправить», «Войти», «Подключить аккаунт» | фон `--lc-primary`, текст и иконки `--lc-primary-ink` (6.29:1) | фон `--lc-primary-hover` (в light — #2ea32d, чернила дают 4.53:1) | фон green-700 (light) / green-500 + затемнение (dark) | opacity .55 | кольцо §6.2 |
| **Secondary (outline)** — «Передать», «Экспорт», «Переподключить» | фон прозрачный, граница `--lc-border-strong`, текст `--lc-text-1` | фон `--lc-bg-2`, граница green-600 | фон green-50 | opacity .55 | кольцо §6.2 |
| **Ghost (subtle)** — иконки-действия, «Отмена», третьестепенное | фон прозрачный, текст `--lc-text-2` | фон `--lc-bg-2`, текст `--lc-text-1` | фон green-50 | opacity .55 | кольцо §6.2 |

Опасный вариант (danger) существует для Secondary и Ghost: текст/граница `--lc-danger`,
hover-фон `--lc-danger-subtle`. Filled-danger — только в подтверждающих модалках
(«Отключить аккаунт»): фон #dc3545, текст #ffffff (4.53:1 — проходит AA впритык,
поэтому вес 600). Кнопка с загрузкой: спиннер вместо текста, ширина не прыгает
(`min-width` фиксируется до клика).

Правило белого текста: белым по зелёному — **только** на green-700 (бейджи). На кнопках
500/600 — всегда чернила `--lc-primary-ink`. Это осознанное решение системы, см. §6.1.

### 4.2. Поля ввода

Высота 36, радиус 8, фон `--lc-bg-0`, граница `--lc-border-strong`, текст 14
`--lc-text-1`, плейсхолдер `--lc-text-3`. Hover: граница `--lc-text-3`. Focus: граница
`--lc-focus-border` + кольцо `--lc-focus-ring` (3px). Ошибка: граница `--lc-danger`,
подпись 13px `--lc-danger-text` под полем — всегда текстом, никогда только цветом.
Disabled: фон `--lc-bg-1`, opacity .55. Лейбл: 13/600 `--lc-text-2`, над полем, 4px зазор.
Поле поиска — с иконкой-лупой слева и клавишной подсказкой `Ctrl+K` справа (капсула
13px на `--lc-bg-2`, исчезает при фокусе).

`MessageInput` (композер): авторастущая textarea 1→6 строк, далее внутренний скролл;
фон `--lc-bg-0`, граница сверху `--lc-border`; в режиме заметки (🗒) весь композер
перекрашивается в `--lc-bubble-note` с текстом-подсказкой «Заметка — клиент её не увидит»,
кнопка отправки становится жёлтой — режим невозможно перепутать.

### 4.3. Чипы тегов

`conversations.tags` (DESIGN §4.4): высота 24, радиус 12 (полная капсула), 13/500,
паддинг 2px 10px. Обычный тег: фон `--lc-bg-2`, текст `--lc-text-2`, граница
`--lc-border`. Кликабельный (фильтр по тегу) — hover: граница green-600.
**«негатив»** (вешает классификатор, DESIGN §4.3) — единственный семантически опасный

в строке списка такой диалог дополнительно получает точку danger слева от времени.
Тег «контакт собран» (бот, DESIGN §4.2): фон green-50, текст green-700 (4.60:1).
Удаляемый чип (в редакторе) — крестик 16px ghost справа.

### 4.4. Бейджи непрочитанных

Капсула min-width 20, высота 20, радиус 10, 13/600, `--lc-unread-bg`/`--lc-unread-text`.
Больше 99 → «99+». Позиции: строка списка (справа, вместо времени при hover — нет,
рядом с временем), вкладка фильтра («Новые 7»), иконка «Чаты» в сайдбаре (сумма),
title вкладки «(3) LeadChat» и бейдж трея — один и тот же `unreadStore` (03 §3.5).
Бейдж «⚑ передан вам» — не число, а флажок green-700 с тултипом «Передал(а): Мария —
"торгуется, дай скидку"». Бейдж «🤖» в строке — диалог сейчас ведёт бот.

### 4.5. Статусные пилюли диалога

Высота 24, радиус 12, 13/600, точка-индикатор 6px слева от текста:

| Статус | Текст | Токены |

| `new` | **Новый** | `--lc-status-new-*` (голубой: «требует человека», громче остальных) |

### 4.6. Аватары

Размеры 24 / 32 / 40 (список — 40). Фото клиента из Авито; fallback — инициалы
(первые буквы двух слов имени, одна — если слово одно) 14/600 на детерминированном

### 4.7. Пузыри сообщений — 5 типов

Общее: max-width 62% ленты (мобильный — 86%), радиус 12, «хвостовой» угол со стороны
отправителя — 4px; паддинг 8px 12px; время 13 `--lc-text-3` в правом нижнем углу;
серии (§3.3) схлопывают повторные аватары/имена. Разметка (классы — по BEM от `.msg`):

```html
<!-- 1. Входящее (клиент) — слева -->
<div class="msg msg--in" role="listitem">
  <div class="msg__avatar"><!-- Avatar 32 --></div>

<!-- 2. Исходящее (оператор) — справа -->
<div class="msg msg--out" role="listitem">
  <div class="msg__bubble">                <!-- bg: --lc-bubble-out -->
    <span class="msg__author">Анна Смирнова</span> <!-- если операторов ≥2 -->

  </div>
</div>

<!-- 3. Бот — справа, отличим с первого взгляда -->
```

строка 13px `--lc-danger-text`: «Не отправилось · Повторить» (кнопка-ссылка).
Вложения: изображения — превью 240px по длинной стороне, радиус 8, клик — лайтбокс;
файлы — строка с иконкой типа, именем и размером.

### 4.8. Тосты

Правый нижний угол, ширина 360, радиус 12, `--lc-shadow-2`, фон `--lc-bg-0` (dark:
`--lc-bg-2`), полоса слева 3px цвета семантики, заголовок 14/600, текст 13 `--lc-text-2`.
Автозакрытие: success 4с, info 6с, error — не закрывается сам (есть действие: «Повторить»,
«Переподключить»). Максимум 3 в стеке, старшие схлопываются в «ещё N». Hover — таймер
на паузу. Появление: slide-up + fade 250мс (§5.3). Критичные события идут в тосты только
если пользователь не видит контекста ошибки на экране (иначе — инлайн у места ошибки).

### 4.9. Скелетоны

Показываются при загрузке >200мс (раньше — ничего, чтобы не мигало). Форма повторяет
контент: список — 8 строк-скелетов 76px (круг 40 + две полосы 60%/40%); лента — 3–4
пузыря переменной ширины по обеим сторонам; карточка клиента — заголовок + 4 строки.
Цвет: `--lc-bg-2` c бегущим бликом `rgba(255,255,255,.4)` (dark: `rgba(255,255,255,.06)`),
цикл 1.2с. При `prefers-reduced-motion` блик статичен. Повторная загрузка уже виденных
данных скелетоны не показывает — данные отдаёт кэш TanStack Query (03 §2), обновление тихое.

### 4.10. Пустые состояния

Формат: эмодзи-«иллюстрация» 40px → заголовок 16/600 → строка 14 `--lc-text-2` → CTA
(если у пользователя есть право на действие — иначе без CTA). Тексты — §7.3.

| Где | Иллюстрация | Заголовок | CTA |
|---|---|---|---|
| Список, вкладка «Мои», пусто | 🌿 | «Пока тихо» | «Посмотреть новые» → вкладка Новые |
| Вкладка «Новые», пусто | ✅ | «Все диалоги разобраны» | — |
| Поиск без результатов | 🔍 | «Ничего не нашлось» | «Сбросить фильтры» |
| Диалог не выбран (центр) | 💬 | «Выберите диалог слева» | подсказка про J/K и Ctrl+K |

## 5. Интеракции

### 5.1. Реестр горячих клавиш

Единый реестр в `features/hotkeys` (одна точка регистрации — конфликты видны в коде).
Windows-первый продукт: базовый модификатор Ctrl (на macOS — ⌘ автоматически).

| Клавиши | Действие | Контекст |
|---|---|---|
| `Enter` | Отправить сообщение/заметку | композер (пустое поле и двойной Enter блокируются — 03 §3.4) |
| `Shift+Enter` | Перенос строки | композер |
| `Ctrl+K` | Фокус в поле поиска по диалогам (имя/текст/телефон); с другого экрана — переход в /chats с фокусом в поиске | глобально |
| `/` | Быстрые ответы «⚡» (поиск по шаблонам, переменные `{имя}`, `{менеджер}`) | композер, только если поле пустое; иначе `/` — обычный символ |
| `J` / `K` или `↓` / `↑` | Следующий / предыдущий диалог в списке | фокус вне полей ввода |
| `Alt+↓` / `Alt+↑` | Следующий / предыдущий диалог с непрочитанными | экран /chats |
| `Enter` (в списке) | Открыть выбранный диалог, фокус в композер | список |
| `Esc` | Закрыть по порядку: меню → модалку/Drawer → режим заметки → очистить поиск (вернуть вкладку); в списке — снять выделение | глобально, «луковица» |
| `Ctrl+Shift+N` | Переключить композер в режим заметки 🗒 | открытый диалог |
| `Alt+1..4` | Вкладки Мои / Все / Новые / Закрытые | экран /chats |
| `Ctrl+Shift+L` | Развернуть/спрятать окно LeadChat из любого приложения | **глобальный, только десктоп** (04 §2, регистрируется в Rust) |

Все хоткеи продублированы видимыми элементами UI — клавиатура ускоряет, но ничего
не прячет. Подсказки: капсулы-клавиши в тултипах кнопок и капсула Ctrl+K в поле поиска (§4.2).

### 5.2. Фокус-порядок рабочего места

Tab-цепочка `/chats`: сайдбар → вкладки-фильтры → поиск → список диалогов (**одна**
tab-остановка, внутри — roving tabindex, стрелки/J/K) → шапка диалога (статус, Передать)
→ лента (одна остановка, стрелки по сообщениям — для чтения скринридером и действий
«Повторить») → панель композера (⚡, 📎, 🗒 → textarea → Отправить) → карточка клиента.
После открытия диалога из списка фокус — сразу в textarea (менеджер пришёл отвечать).
После отправки — остаётся в textarea. Модалки и Drawer — focus trap, Esc возвращает
фокус на вызвавший элемент.

### 5.3. Анимации

| Токен | Значение | Где |
|---|---|---|
| `--lc-motion-fast` | 150мс, `cubic-bezier(0.2, 0, 0, 1)` | hover/active, fade тултипов, появление нового пузыря (fade + 4px подъём) |
| `--lc-motion-base` | 250мс, тот же easing | модалки, Drawer, тосты, раскрытие меню, смена вкладок |

Ничего дольше 250мс. Перестройка списка при новом сообщении — **без** анимации перелёта
(строки просто меняются местами: за день это сотни событий, движение утомляет);
единственный маркер — короткая вспышка фона строки green-50 → прозрачный за 250мс.
Скролл к новому сообщению — `behavior: auto` (мгновенно), плавный скролл только по
явному действию пользователя (клик по «↓ к последним»).

### 5.4. Звук уведомлений

Механика — 03 §3.5 (`new-message.mp3` ~20КБ, троттлинг 2с); правила поверх:

1. Звук — только входящие от клиента (`direction=in`, `sender_type=client`). Сообщения
   бота, коллег и эхо своих — беззвучны.
2. Открытый активный диалог в сфокусированной вкладке — без звука (человек и так видит).
3. Тумблер звука — в профиле и быстрый — в шапке списка (иконка 🔔/🔕, состояние в
   `useChatUiStore`). Отключение звука не отключает тосты и бейджи.
4. Десктоп: матрица «когда показывать тост» — 04 §4.1, троттлинг потока — 04 §4.3;
   звук воспроизводит только один источник (если показан нативный тост со звуком системы —
   свой mp3 не играем).
5. Приоритетное исключение: диалог с тегом «негатив» звучит даже при выключенном общем
   звуке (отдельный тумблер «тихий режим полностью» — в профиле).

## 6. Доступность

### 6.1. Контрасты (проверено арифметически, WCAG 2.1)

Формула относительной яркости WCAG; AA: ≥4.5:1 обычный текст, ≥3:1 крупный текст и
нетекстовые элементы. Ключевые пары:

| Пара | Светлая | Тёмная | Вердикт |
|---|---|---|---|
| text-1 / bg-0 | #212529/#ffffff — **15.43:1** | #e9ecef/#121517 — **15.46:1** | AA (и AAA) |
| text-1 / bg-1 | **14.63:1** | #e9ecef/#191d21 — **14.29:1** | AA |
| text-2 / bg-0..1 | #495057 — **8.18 / 7.76:1** | #adb5bd — **8.17:1** (bg-1) | AA |
| text-3 / bg-0 | #6c757d/#ffffff — **4.69:1** | #868e96/#191d21 — **5.10:1** | AA |

| Белый / green-700 | **5.44:1** | — | AA — бейдж непрочитанных, ссылки наоборот |

Правила, вытекающие из таблицы:

- **Текст на зелёном**: 500/600 — только `--lc-primary-ink`; белый — только на 700+.
  Иконки на зелёных заливках — те же чернила (нетекстовый порог 3:1 белый на 500 тоже
  не проходит — 2.36:1).
- **text-3 на подложках**: время/метаданные на `--lc-bg-1/2` — либо размер ≥18px, либо
  замена на `--lc-text-2` (в выбранной строке списка на green-50 метаданные автоматически
  переключаются на text-2 — 6.90:1). Кратковременный hover-фон строки (#f1f3f5) с
  text-3 4.22:1 — известный компромисс, статичных экранов с такой парой нет.
- Декоративные границы (#dee2e6) под порог не попадают (не несут информацию); смысловые
  границы (ошибка поля, failed-пузырь) — danger ≥4.5:1. Идентификацию поля обеспечивают
  лейбл и фон, при фокусе — кольцо 3.28:1.

### 6.2. Фокус-индикаторы

`:focus-visible` (не `:focus` — мышь колец не рисует): обводка 2px `--lc-focus-border`
+ внешний halo 3px `--lc-focus-ring`, `outline-offset: 2px`; радиус кольца следует
радиусу элемента. В списках (roving tabindex) выбранный элемент дополнительно имеет
фон green-50 — фокус и выбор различимы одновременно.

### 6.3. ARIA-паттерны

- **Список диалогов**: `role="listbox"` + `aria-label="Диалоги, вкладка Мои"`, строки —
  `role="option"` c `aria-selected`; roving tabindex (в таб-цепочке — одна остановка);
  `aria-setsize`/`aria-posinset` — потому что DOM виртуализирован (03 §4.1) и реального
  размера в нём нет. Текст опции собирается по шаблону: «Иван Петров, iPhone 13, 3
  непрочитанных, последнее в 12:40, есть тег негатив».
- **Лента сообщений**: `role="log"` + `aria-live="polite"` `aria-relevant="additions"` —
  новые сообщения озвучиваются, история — нет. Пузырь: `role="listitem"`,
  `aria-label` = «Клиент, 12:40: текст» / «Заметка, видно только сотрудникам: …».
  Скринридеру заметка и бот всегда объявляются словами, не только цветом/иконкой.
- **Счётчики**: бейджи — `aria-label="3 непрочитанных"`; вкладки-фильтры —
  `role="tablist"`, счётчик внутри `aria-label` вкладки.
- **Тосты**: success/info — `role="status"`, ошибки — `role="alert"`.
- **Статусная пилюля-селект**: нативная семантика Mantine `Select` +
  `aria-label="Статус диалога: В работе"`; у observer — обычный текст с тем же label.
- Иконки-кнопки без текста (📎, ⚡, 🗒) — обязательный `aria-label` («Прикрепить файл»,
  «Быстрые ответы», «Режим заметки»).

### 6.4. prefers-reduced-motion

`@media (prefers-reduced-motion: reduce)`: все transition/animation → `1ms`
(не `none` — события `transitionend` должны срабатывать), блик скелетонов статичен,
вспышка строки заменяется мгновенной сменой фона, автоскролл — без smooth. Настройка ОС
уважается всегда, отдельного тумблера в профиле не делаем (не плодим состояния).

## 7. Тон текстов интерфейса

### 7.1. Принципы

По-человечески, коротко, без канцелярита и без вины пользователя. Обращение — на «вы»
(без Вы с большой). Ошибки называют, что случилось и что сделать, — не код и не «упс».
Эмодзи — только в пустых состояниях и онбординге, никогда в ошибках и подтверждениях
опасных действий.

### 7.2. Словарь терминов (обязательный, RU)

| Говорим | Не говорим |
|---|---|
| **Диалог** | чат-тред, тикет, обращение, беседа |
| **Новый / В работе / Закрыт** | open/pending, «активный», «завершён» |
| **Взять в работу** | assign, «назначить себя» |
| **Передать** (коллеге) | форвардинг, реассайн, «шарить» |
| **Заметка** (внутренняя) | комментарий, private note |
| **Быстрый ответ** | шаблон*, канд-респонс (*«шаблоны» — допустимо в настройках как раздел) |
| **Аккаунт Авито** | интеграция, канал (канал — термин архитектуры, не UI) |
| **Сотрудник** | юзер, пользователь (в админке допустимо «пользователи» только в audit-контексте) |
| **Менеджер / Руководитель / Наблюдатель / Администратор** | роли по-английски |
| **Непрочитанные** | анриды |
| **Объявление** | листинг, item |
| **Подключить / Переподключить / Отключить** (аккаунт) | авторизовать, приаттачить |

### 7.3. Шаблоны текстов

Пустые состояния (§4.10):
- «Пока тихо. Новых сообщений нет — загляните во вкладку "Новые" или выпейте кофе ☕»
- «Все диалоги разобраны. Отличная работа!»
- «Ничего не нашлось. Проверьте запрос или сбросьте фильтры»

Ошибки:
- Сеть: «Нет соединения. Проверяем каждые несколько секунд — как только сеть появится,
  всё дошлём» (+ статус-строка reconnect из 03 §3.2).
- Отправка: «Не отправилось. Авито не приняло сообщение — Повторить» (кнопка).
- Права (403 `read_only_role`, 01 §12): «Режим просмотра — отвечать может менеджер.
  Назначьте менеджера или передайте диалог» (плашка head, DESIGN §5.2).
- Токен аккаунта (`needs_reauth`): «Аккаунт "LP-Москва" отключился от Авито.
  Переподключите его, чтобы сообщения снова приходили» (только admin видит CTA).
- Валидация: конкретно и рядом с полем: «Похоже, это не телефон. Формат: +7 900 000-00-00».

Подтверждения опасного: заголовок — глагол действия («Отключить аккаунт?»), тело — одно
последствие («Сообщения с этого аккаунта перестанут приходить в LeadChat»), кнопки —
«Отключить» (danger) / «Отмена». Никогда «Вы уверены?».

### 7.4. Формат времени (RU, единый хелпер `formatTime`)

| Когда | Список диалогов | Лента (разделители) | Метка сообщения |
|---|---|---|---|
| Сегодня | `14:02` | «Сегодня» | `14:02` |
| Вчера | `вчера` | «Вчера» | `14:02` |
| Этот год | `12 мар` | «12 марта» | `14:02` |
| Раньше | `12.03.2024` | «12 марта 2024» | `14:02` |

Часовой пояс — локальный для сотрудника; в тултипе любой метки — полная дата-время.
В статистике длительности: «2 мин», «1 ч 12 мин», «3 дн» — без секунд, кроме времени
первого ответа < 1 мин («48 сек» — этим гордимся). Числа: пробел-разделитель тысяч,
«₽» после числа с неразрывным пробелом («8 900 ₽»).
